## 🎯 What is AISec-Scanner?

**AISec-Scanner** is a comprehensive security scanner designed specifically for AI and ML projects. It detects:

- 🔓 **Prompt Injection Vulnerabilities** - The #1 threat to AI applications in 2026
- 📦 **Compromised Dependencies** - Malicious or vulnerable libraries in your supply chain
- 🧠 **Malicious Model Files** - Hidden code in PyTorch, TensorFlow, or ONNX models
- 🔑 **Exposed Secrets** - API keys, passwords, and tokens in your codebase
